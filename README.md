# claudopus

A Claude Code mod that greets you at the start of each interactive session with a colour pixel-art dinosaur above the prompt, roaring "GRAAAAAAAAA Here's the mighty Claudopus 🦖". The dinosaur goes away as soon as you send your first message.

## Install

At the prompt of a terminal session:

```
/plugin install claudopus --marketplace ewendufour/claudopus
```

Answer `y` to add the marketplace, then pick a scope (user scope first, chosen with Enter).

From a shell:

```
claude plugin install claudopus --marketplace ewendufour/claudopus
```

In the desktop app, where `/plugin` does not run: click + next to the prompt box, then Plugins, Add marketplace with `ewendufour/claudopus`, then Add plugin.
